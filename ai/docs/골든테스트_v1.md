# 골든 테스트 세트 v1 — 데이터/AI 파트 시험지

> 기준: 합성 데이터 v2(`homework_v2/`), 번역표·지표 정의서 v3, 1~4차 멘토링 + 회신.
> 각 줄은 "이 입력이 들어오면 이 결과가 나와야 한다". 나중에 pytest 한 줄 = 표 한 줄.
> 상태 값은 `match_status` 기준: EXACT / NORMALIZED / MANUAL / UNREGISTERED / MISSING.

## 사용법
- A·B는 파서를 만들면서 바로 돌릴 수 있는 것(입력 파일이 있음).
- C·D는 `seed_번역표_장소표_v1.sql`의 데이터가 있어야 함 → 파서 단계에선 같은 내용을 Python dict로 들고 테스트.
- E는 백엔드 집계 함수가 나오면 그쪽 테스트. 데이터/AI는 D14까지 책임.
- 회사 AI로 교체한 뒤에도 A~D는 그대로 돌아가야 함(AI는 A20·B10에서만 관여).
