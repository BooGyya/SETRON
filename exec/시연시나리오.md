# SETRON 시연 시나리오 (7분)

담당자가 팀장의 요청 하나("이번 주 평택 C4 버전 현황 보고와 업데이트 대상 정리")를 처음부터 끝까지 해결하는 흐름으로, 기업 요구사항 6개를 모두 보여 줍니다. 클릭 위치는 앱 기본 창(1920×1080, 왼쪽 메뉴 펼침) 기준입니다.

> `[시연 DB 값]`은 시연 직전에 화면에 나오는 실제 값으로 채웁니다. 팀 시연 대본과 순서 · 질문을 맞춰 수정해 주세요.

---

## 0. 준비 (시연 전)

| 순서 | 할 일 |
| --- | --- |
| 1 | 시연 DB 초기화: `prepare_demo_db.bat`(Windows MySQL) 또는 `prepare_docker_demo_db.bat`(Docker) — 설비 300대 · 기준일 6개 · 목표 N 11쌍 |
| 2 | 앱 실행: `SETRON.exe` (또는 `uv run --locked --env-file <설정 파일> python -m setron`) → 상단 "MySQL DB 저장 자료" 확인 |
| 3 | Excel에 열어 두기: `평택설비현황표_교육용.xlsx`, `P_PJT_M-O5 … 교육용.xlsx` |
| 4 | 인터넷 · AI 키 확인 (AI 추출 · AI 분석). 응답이 늦을 때를 대비해 시연 녹화 영상 준비 |

## 2. 데이터 가져오기 — 요구사항 ③ · HITL (1:30)

| 순서 | 화면 · 위치 | 클릭 · 입력 | 보여 줄 것 |
| --- | --- | --- | --- |
| 2-1 | 왼쪽 메뉴 | **데이터 가져오기** → 위쪽 **Excel** 탭 | 가져오기 화면 |
| 2-2 | 1. Excel 통합문서 · 시트 선택 (위쪽) | **열린 통합문서 불러오기** → 통합문서 `평택설비현황표_교육용` · 시트 `P1` · 자료 종류 `설비 현황` → **시트 읽기** | 2. 원본 미리보기에 엑셀 그대로 표시 |
| 2-3 | 1. 영역 오른쪽 | **AI 추출** | "추출 완료", 3. 검토 표에 설비 · 라인 · PM · 버전 · 공정 정리 |
| 2-4 | 3. 검토 표 (가운데) | 설비호기 칸 하나 클릭 | 원본 셀 위치 표시 (꼬리표) |
| 2-5 | 3. 검토 표 | 버전 칸 하나 더블클릭 → 값 수정 → Enter | 수정한 칸이 "수정됨"으로 표시 (사람이 검토 · 수정) |
| 2-6 | 검토 표 아래 | 기준 날짜 `[시연 날짜]` · Site `평택` → **모든 행에 적용** | 빈 칸 채움, 검토 항목(자동 검사)에 오류 없음 |
| 2-7 | 오른쪽 아래 | **검토 완료 · 저장** | 저장 완료 안내 |

시연 뒤에는 0-1로 시연 DB를 다시 만듭니다.

## 응답이 늦거나 오류가 날 때

| 상황 | 대처 |
| --- | --- |
| AI 답이 늦음 | "같은 질문의 결과로 보여 드리겠습니다" → 미리 받아 둔 대화 · 녹화 영상 |
| AI 추출이 오래 걸림 | 미리 저장해 둔 결과 화면으로 이동 |
| DB 접속 실패 (상단 안내) | 앱 재실행, 안 되면 녹화 영상 |
