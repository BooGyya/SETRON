# 대시보드

기준: 2026-11-16, develop f0cfc8d. 코드: `ui/dashboard.py`, `ui/dashboard_data.py`, `ui/dashboard_charts.py`, `ui/dashboard_matrix.py`, `ui/query_panel.py`, `ui/group_dialog.py`, `ui/version_filter_dialog.py`, `ui/equipment_list_drawer.py`, `ui/app.py`(연결).

왼쪽 첫 메뉴 **대시보드**. 앱을 켜면 처음 보이는 화면이다. 위쪽 공통 조회 조건으로 범위를 정하고, 숫자 카드 5개와 보기 4가지로 목표 N 달성 현황을 본다.

## 화면 구성

| 영역 | 화면 글자 |
| --- | --- |
| 조회 조건 (공통, 버전 히트맵과 같은 조건) | `기준날짜` · `분류` · `사업장` · `라인` · `설비군`, 조건 초기화 · 조회(돋보기) 아이콘. 아래 **[기준 버전 설정]** · **[조회 버전 설정]**과 조회 상태 배지 |
| 숫자 카드 | **목표 N 이상 달성률**(강조색 카드) · **분석 대상** · **목표 미달** · **버전 확인 필요** · **안전·결함 위험 후보** |
| 보기 탭 | **[히트맵]** / **[원형 그래프]** / **[막대 그래프]** / **[꺾은선 그래프]** |
| 꺾은선 그래프 전용 | 간격 **지정 일수 / 1주 / 1개월 / 3개월** |
| 히트맵 전용 범례 | `목표 달성률` · 목표 달성 · 목표 미달 · 확인 필요 · 위험 후보 |
| 막대 · 꺾은선 전용 | 설비군 칩(누르면 그 설비군 선을 끄고 켬) + 전체 선택/해제 |

머리 줄 오른쪽 `설비 목록` 버튼은 대시보드에서 숨긴다(`app.py` `list_action.setVisible`). 설비 목록은 표 칸 · 위험 배지를 눌러 오른쪽 패널로 연다.

## 조회 조건

- `기준날짜`: 날짜를 고르고 조회를 누르면 **그 날짜까지 저장된 가장 최근 관측일** 자료로 계산한다. [꺾은선 그래프] 탭에서는 같은 칸이 시작 ~ 종료 기간으로 바뀐다.
- `분류` · `사업장` · `라인` · `설비군`: 누르면 다중 선택 팝업(검색 · 전체 선택 · [선택 완료])이 열린다([공통 드롭다운](dropdown-behavior.md#조회-조건-필드는-드롭다운이-아니다)).
- 조건을 바꾸고 조회를 누르기 전에는 상태 배지가 `선택 변경 · 재적용 필요` 등으로 바뀌고, 결과는 마지막으로 적용한 조건 그대로다.
- 조건 초기화: `분류`~`설비군`을 전체로, 기준날짜를 오늘(최신 관측)로, 조회 버전 선택도 전체로 되돌린다(조회를 눌러야 반영). 꺾은선 기간은 저장된 첫날 ~ 마지막 날로, 간격은 처음 값으로 돌린다(다음 조회 때 반영).
- **[기준 버전 설정]**: `SETRON · 기준 버전 설정` 창. 계열 · 모델을 고르고 버전별 단계(N+1 이상 · N · N-1 · N-2 이하)를 정해 [저장]한다. [수동 설정]으로 버전별 칸을 펼치고, `저장 이력`에서 되돌리기를 할 수 있다. 저장 뒤 조회를 눌러야 반영된다. 이 창의 단계 칩 색은 N-1 노랑 · N-2 이하 빨강이다(`ui/group_data.py` `TIER_COLORS`). 버전 히트맵 타일 기본 팔레트(N-1 연분홍 · N-2 이하 분홍, `ui/appearance_data.py`)와 다르다.
- **[조회 버전 설정]**: 조회에 넣을 버전을 고르는 팝업([버전 리플레이](replay-ver5.md#조회-버전-설정-팝업)와 같은 창). 목표 N을 바꾸지 않는다.

## 숫자 카드

| 카드 | 값 |
| --- | --- |
| 목표 N 이상 달성률 | N 이상 ÷ (N 이상 + N 미만). 단위는 **설비 · SW 계열 건**. 판단 불가는 분모에서 뺀다. 계산할 수 없으면 `계산 불가` |
| 분석 대상 | HPA를 뺀 실제 호기 수(같은 호기는 한 대) |
| 목표 미달 | 한 계열이라도 N 미만인 호기 수. 0대인데 판단 못 한 대상이 있으면 `판단 불가` |
| 버전 확인 필요 | 판정할 SW가 없거나(미확인) 판단 불가 계열이 있는 호기 수 |
| 안전·결함 위험 후보 | 등록된 위험 기준으로 위험 후보가 된 호기 수. 0대인데 위험 미확인이 있으면 `미확인` |

- 0대가 '문제 없음'으로 읽히지 않게, 판단하지 못한 대상이 있으면 숫자 대신 글자를 보인다(`dashboard_data.count_value`).
- 위험 후보는 목표 달성과 따로 판정한다. 목표 미달을 위험으로 추론하지 않는다.
- 카드 색은 설정 › 대시보드 색상(기본 / 색각 보정 / 직접 선택)을 따른다([설정](settings-ver5.md)).

## 보기

### 히트맵 (표)

- 행: **사업장 · 원본 구역(라인)**, 마지막 행 `전체`. 왼쪽 머리 `사업장 / 라인`.
- 열: 설비군(KCTC 계열 설비군은 `KCTC` 한 열로 합침), 마지막 열 `전체`.
- 칸: 큰 글자 달성률(%), 아래 `a/b건`. 위험 후보가 있으면 경고 아이콘 + 대수 배지, 없고 판단 불가가 있으면 `미확인n`. 자료가 없으면 `—`, HPA만 있으면 `분석 제외`, 달성률을 못 내면 `정보 부족`.
- 칸 색: 모든 대상이 판정되고 SW 미등록이 없으면 목표 달성색, 아니면 목표 미달색, 달성률을 못 내면 확인 필요색.
- 칸에 마우스를 올리면 N 이상 · N 미만 · 정보 부족 건수(또는 정보 부족 사유)가 보인다. 행 · 열 머리에는 총 적용률 · 분석 대수 · HPA 제외 · SW 미등록 · 위험 후보 수가 보인다. 위험 배지 툴팁에는 적용 위험 / 미적용 위험 대수와 `판정 근거 미연결` 대수가 보인다.
- **칸을 누르면** 그 범위의 설비 목록이, **위험 배지를 누르면** 위험 후보만 오른쪽 설비 목록 패널(`ui/equipment_list_drawer.py`)에 열린다. 목록 행을 누르면 같은 패널에서 설비 상세([히트맵 설비 상세](heatmap-detail-sidebar.md)와 같은 카드)를 본다.
- 표가 넓으면 머리 행 · 첫 열을 고정한 채 안에서 스크롤한다(`ui/dashboard_matrix.py`).

### 원형 그래프

- N 이상 · N 미만 · 판단 불가 건수의 도넛. 가운데 달성률과 `a / b건 목표 달성`.
- 오른쪽 칩: 달성 · 미달 · 확인 필요, 각 건수와 비율. 마우스를 올리면 건수 · 비율과 해당 설비 대수가 보인다.
- 달성률은 판단 가능 건 기준, 구성비는 판단 불가를 포함한 전체 건 기준이다.

### 막대 그래프

- 가로축은 구역(사업장 · 라인), 막대는 설비군별, 세로축 `목표 N 이상 적용률 (%)`.
- 판정할 건이 없는 막대는 `—`, 실제 0%는 `0%`로 따로 표시한다.
- 설비군 칩으로 막대를 끄고 켠다. 값이 있는 설비군만 칩이 켜진다.

### 꺾은선 그래프

- 설비군별 목표 N 이상 적용률 추이. 세로축 `목표 N 이상 적용률 (%)`.
- 기간은 위 `기준날짜` 기간 칸으로 정하고 조회로 확정한다. 간격: **지정 일수**(기본 1일, 다시 누르면 `일수 간격 입력` 창) · 1주 · 1개월 · 3개월.
- 간격 시점은 그 시점 이전 마지막 관측으로 계산한다. 마지막 관측의 달성률이 계산 불가면 그대로 두고 이전 값으로 건너뛰지 않는다(`dashboard_data.trend_window`).
- 기간 안에 계산할 자료가 없으면 `선택한 기간에 달성률을 계산할 수 있는 관측 자료가 없습니다.`
- 그래프가 길면 세로축은 고정하고 그림만 가로로 스크롤한다.

## 안내 문구

- 조회 전: `위에서 조회 조건을 선택하면 결과를 표시합니다.`
- 조건에 맞는 설비가 없음: `조건에 맞는 설비가 없습니다. 조회 조건을 변경하거나 초기화해 주세요.`
- HPA만 있음: `분석 대상 설비가 없습니다. HPA는 전체 설비 수와 적용률·공통 분석에서 제외하며, 설비 목록에서 조회할 수 있습니다.`
- 저장 자료나 선택지가 바뀜: `선택지가 변경되었습니다. 위에서 조회 조건을 다시 선택해 주세요.`

## 데이터 원칙

- 목표 N은 저장된 기준 버전(N 그룹)을 쓴다. 미지정 · 순서 미확인 · SW 미등록은 판단 불가 · 정보 부족으로 보이고 0%로 바꾸지 않는다.
- HPA는 분석 대상 · 달성률에서 빼고 설비 목록에서만 본다. 모델별 대수를 더해 물리 대수를 만들지 않는다.
- 데이터 관리 · 가져오기 · 위험 기준 저장 뒤에는 관리 저장 갱신 경로(`after_management_save`)로 선택지와 결과를 다시 읽는다.
