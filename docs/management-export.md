# 관리값 요약 Excel

데이터 내보내기의 **관리값 요약 Excel**은 연결 DB의 현재 관리값을 `설비현황표`, `릴리즈노트` 두 시트로 저장합니다. 계산 보고서나 원본 Excel 서식을 복원하는 기능과는 다릅니다.

## 출력 대상

- **전체 내보내기**: DB에 남아 있는 관리값 전체를 출력합니다.
- **가져온 파일 선택**: 현재 자료와 연결된 가져오기 목록에서 파일을 하나 이상 체크합니다. 목록에는 파일명·자료 종류·가져온 날짜가 표시됩니다. 같은 이름을 다시 가져온 경우는 날짜로 구분합니다. 이전 자료에 파일명이 기록되지 않았다면 `파일명 미기록`으로 표시합니다.

파일 선택은 입력 작업과 현재 행의 원본 출처 연결을 기준으로 합니다. 같은 현재 행이 여러 선택 파일에 연결되어도 한 번만 출력합니다. 선택한 PM의 설비 정보와 선택한 Item의 현재 릴리즈 정보 등 표시할 부모 값은 함께 포함합니다. 선택한 릴리즈는 현재 연결된 Item을 포함합니다.

**출력 값은 항상 내보내는 시점의 DB 값입니다.** 데이터 관리에서 수정 후 저장한 값은 수정값으로 출력합니다. 삭제 완료된 행은 출력하지 않고 원본 셀·수정 전 값·감사 기록에서 되살리지 않습니다. 관측을 삭제하고 식별자만 남은 호기도 현황표에 넣지 않습니다. 자료가 모두 삭제된 가져오기는 파일 목록에서 제외합니다.

목록의 **새로고침**으로 신규 가져오기·삭제를 반영합니다. 목록을 읽은 뒤 수정·삭제가 있었더라도 내보내기는 현재 DB를 다시 읽습니다.

**전체 선택** 버튼은 모든 파일을 선택하면 **전체 선택 해제**로 바뀝니다. 같은 버튼으로 선택과 해제를 전환합니다. 파일 목록은 화면 높이에 따라 3~8개 행만 표시하며, 나머지 파일은 목록 내부에서 스크롤합니다.

## 분류 선택

- **전체**: 선택한 출력 대상에서 생산 영역이 비어 있는 자료를 포함합니다.
- **Memory / Foundry**: 설비 현황은 저장된 생산 영역으로 구분합니다. 라인 이름으로 생산 영역을 추정하거나 다시 분류하지 않습니다.

릴리즈노트는 선택 범위에서 사용하는 계열과 해당 분류의 등록 계열을 포함합니다. Memory/Foundry가 별도 계열로 등록된 노트는 기존 계열 구분을 사용하며, HPA 등 공통 노트는 저장된 관측 분류를 따릅니다. 연결되지 않은 Item은 전체에 포함하고, 버전 칸은 비워 둡니다.

Memory·Foundry 조건은 전체 내보내기와 파일 선택 모두에 적용됩니다. 파일 선택에서는 해당 파일과 연결되지 않은 릴리즈를 계열 전체에서 추가하지 않습니다.

파일·분류로 범위를 정했는데 두 시트 모두 조건에 맞는 자료가 0건이면 파일을 저장하지 않고 선택을 확인하도록 안내합니다. 생산 영역이 비어 있는 자료는 `전체`에서만 포함하며 Memory·Foundry로 추정하지 않습니다. 자료 종류가 설비현황표뿐이면 릴리즈노트 시트가 비어 있을 수 있으며, 릴리즈노트 파일은 반대로 현황 시트가 비어 있을 수 있습니다.

## 보존하는 값

- `P1F`, `P1D`, `P4H`, `P4D`, `P3-S5` 등 라인 원문, 저장된 생산 영역, 모델, PM, 버전 원문을 유지합니다.
- DFB는 C4와 다른 설비군으로 표시하고 묶어 정렬합니다. 같은 C4 릴리즈를 사용하는 내부 연결은 유지합니다. 라인별 히트맵 Excel도 DFB를 별도 그룹으로 표시합니다.
- HPA와 SW 버전이 없는 관측도 현황 시트에서 제외하지 않습니다.
- 릴리즈의 버전·접미사·출시일·확인 순서와 Item 내용·적용 상태·모델 범위를 포함합니다. Item이 없는 릴리즈와 버전에 연결되지 않은 Item도 전체 출력에서 빠지지 않습니다.
- 사용자용 두 시트에 `SW 계열`·`버전 계열` 열을 노출하지 않습니다. 가져오기에서는 모델·UI·생산 영역으로 기존 등록 계열을 확인합니다.

현황 시트는 **기준일 × 적용 SW × PM**마다 행이 생깁니다. 출력 행 수는 물리 설비 대수와 다를 수 있습니다.

## 다시 가져오기

각 시트를 해당 자료 종류로 읽고 기존 추출·원본 대조·검토·저장 절차를 진행합니다. 앱에서 내보낸 양식은 규칙으로 읽습니다. 여러 사업장 행을 담은 관리 양식은 허용하되, 같은 호기의 사업장 충돌과 HPA 누락 검사는 유지합니다.

원래 DB에 필수값이 없는 행은 빈칸 그대로 출력합니다. 재가져오기 시에도 임의로 날짜·버전·연결 대상을 채우지 않으며, 기존 검토 단계에서 보완해야 합니다. 전체 DB와 원본 출처까지 복원할 때는 SQL 내보내기를 사용합니다.
