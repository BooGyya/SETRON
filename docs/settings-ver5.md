## 저장 범위

개인 테마·메뉴 순서·첫 화면 배치·나의 선택지는 `QSettings(SETRON, Appearance)`에 저장한다. 잘못된 설정 파일은 기본값으로 복구한다. HEX 검증이나 로컬 저장이 실패하면 적용된 설정을 바꾸지 않는다. 색상 편집은 미리보기만 바꾸며, 저장할 때 전체 앱에 반영한다. 시스템 모드는 OS 색상 변경을 따른다.

### 색상·진행 안내 보완

- 밝은 모드의 기존 파스텔 상태색은 그대로 유지한다. 달성률 카드는 강조색으로 면 전체를 채우지 않고 옅은 배경과 강조 숫자로 표시한다.
- 밝은 화면의 `canvas/surface` HEX는 어두운 모드로 상속하지 않는다. 어두운 모드의 직접 선택은 `dark_colors`로 분리 저장한다. Figma 다크 기준은 본문 `#11151C`, 카드 `#242B36`, 입력 `#1B212B`, 선택 `#263250`, 강조 `#8EA2FF`다.
- 버튼 글자는 배경의 상대 휘도 대비로 결정한다. 파란 버튼의 흰 글자를 검게 치환하던 문제와 다크→라이트에서 남던 사이드바 글자색을 수정했다.
- 화면 설정·메뉴/배치·나의 라인/설비군 저장 시 진행 창을 표시한다. QSettings 쓰기는 독립 인스턴스를 사용하는 워커에서 처리하고, 화면 적용은 GUI 스레드에서 묶음으로 나누어 움직이는 진행 막대를 유지한다. 중복 저장과 적용 중 앱 종료를 막고, 실패 시 적용된 설정을 유지한다.
- 관리 데이터 저장·저장 후 재조회에도 진행 창을 표시하며 완료/실패/미확인/취소된 재조회에서 닫는다. 설치 버전 정정에 이미 진행 창이 있으면 중복 창을 열지 않는다. 가져오기·보고서의 기존 진행 창은 유지한다.

현재 위치 저장 서비스에는 정규 Site/Fab/Line 관리 계약이 없다. 위치 연결과 Site·설비군 추가는 **현재 화면 세션의 프론트 작업 공간**이며 회사 DB·원본 관측·분석 결과를 변경하지 않는다. 확인창과 완료 안내에 이 범위를 표시한다. 행/선택이 바뀐 뒤 오래된 확인창에서 적용할 수 없다. 실제 회사 DB 저장·분석 반영은 별도 연동 범위다. 피그마의 `DEMO-LOC-001` 시연 버튼 대신 현재 공급자의 실제 선택지로 같은 검토·취소·확인 흐름을 제공한다.

## 공통 테마

기존 화면별 QSS의 원본을 보존하고 공통 토큰으로 변환한다. 라이트 복귀 시 원본 기준으로 다시 계산한다. 직접 그리는 표/배지는 `ui_color`를 사용하고 QtCharts 배경·축·범례도 갱신한다. 판정·수치 계산과 회사 AI 초기 대화 내용은 변경하지 않는다. 원본 아이콘은 로컬 자산을 유지하고 다크 모드에서 같은 크기로 대비를 조정한다.

Qt 기본 API: [QPalette](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QPalette.html), [시스템 색상 모드](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QStyleHints.html), [QSettings](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QSettings.html).
