## 화면 구성

탭은 **화면 · 테마** 하나다. 왼쪽에 설정 카드, 오른쪽에 미리보기가 있다(창이 좁으면 위아래로 놓인다).

| 카드 | 고르는 것 |
| --- | --- |
| 표시 모드 | 밝게 / 어둡게 / 시스템 |
| 글자 크기 | 작게 / 보통 / 크게 (저장하면 앱의 모든 화면에 적용) |
| 포인트 색상 | Blue / Teal / Violet / 직접 선택(HEX 입력 + 팔레트 버튼) |
| 대시보드 색상 | 기본 / 색각 보정 / 직접 선택. 칸: 목표 달성 · 목표 미달 · 확인 필요 · 안전·결함 위험 후보 · 달성률 강조색 |
| 버전 히트맵 색상 | 기본 / 색각 보정 / 직접 선택. 칸: N+1 이상 · N · N-1 · N-2 이하 · 비교 불가 · HPA · 위험 후보 테두리 |
| 배경 · 카드 색상 | 화면 배경 · 카드 배경 |

- 아래 버튼: [기본값으로] · [취소] · [저장].
- 색 칸은 `#RRGGBB`로 적거나 오른쪽 팔레트 버튼으로 연다(`… 색상 선택` 창, [취소]/[확인]).
- 미리보기는 `미리보기 화면 선택`에서 대시보드 / 버전 히트맵을 고른다. 색 칸을 고치면 해당 미리보기로 바뀐다. 미리보기 숫자는 예시 데이터다.
- 직접 선택한 색이 있으면 그 카드의 팔레트는 자동으로 `직접 선택`이 되고, 나머지 색은 고르기 전 팔레트 값을 유지한다.

### 히트맵 기본 팔레트 색

`ui/appearance_data.py`의 `HEATMAP_STANDARD`(밝은 모드):

| 단계 | 색 |
| --- | --- |
| N+1 이상 | 진한 연초록 `#a9dbbd` |
| N | 연초록 `#ddf4e5` |
| N-1 | 연분홍 `#fce4e7` |
| N-2 이하 | 분홍 `#f6c5cd` |
| 비교 불가 · HPA | 회색 `#eceef1` |
| 위험 후보 테두리 | `#c9485e` |

참고: 버전 히트맵의 **[기준 버전 설정]** 창(`ui/group_data.py` `TIER_COLORS`)의 단계 칩은 이 팔레트를 쓰지 않고 N+1 이상 진초록 · N 연초록 · **N-1 노랑 · N-2 이하 빨강** · 비교 불가 회색으로 따로 정해져 있다. 두 곳의 색이 다르다.

## 저장 범위

- 개인 설정은 이 PC의 `QSettings("SETRON", "Appearance")`에 저장한다. 업무 데이터 · 목표 N · 판정은 바꾸지 않는다.
- 잘못된 설정 값은 기본값으로 읽는다. HEX 검증이나 저장이 실패하면 적용된 설정을 바꾸지 않는다(`개인 설정을 저장하지 못했습니다. 이전 설정을 유지합니다.`).
- 색 편집은 미리보기만 바꾼다. [저장]을 눌러야 전체 앱에 적용되고 `저장 완료 · 모든 화면에 적용했습니다.` 토스트가 뜬다. [취소]는 저장된 설정으로, [기본값으로]는 기본값 미리보기로 돌린다.
- 화면 배경 색은 입력 중에도 앱 배경에 미리 보인다. 설정 화면을 떠나면 미리보기는 지워진다.
- 저장 중에는 진행 창(`화면 설정 저장 중` → `화면에 적용 중`)을 띄우고, 중복 저장을 막는다. QSettings 쓰기는 워커에서 자기 인스턴스로 한다.
- 시스템 모드는 OS 색상 변경을 따른다.

위치 · Site · 라인 관리는 이 화면에 없다. **데이터 관리 › 설비현황 › 위치**에서 하고, DB `app_setting`(`registered_sites.v1`, `registered_lines.v1`)에 저장된다([데이터 관리](data-management.md)). `ui/settings_location.py`는 남아 있지만 어떤 화면에서도 쓰지 않는다.

## 색상 · 진행 안내 보완 (11-08)

- 밝은 모드의 기존 파스텔 상태색은 유지한다. 달성률 카드는 강조색으로 면 전체를 채우지 않고 옅은 배경과 강조 숫자로 표시한다.
- 밝은 화면의 배경 · 카드 HEX는 어두운 모드로 넘기지 않는다. 어두운 모드의 직접 선택은 `dark_colors`로 따로 저장한다. 어두운 기본값은 본문 `#11151C`, 카드 `#242B36`, 입력 `#1B212B`, 선택 `#263250`, 강조 `#8EA2FF`다.
- 버튼 글자는 배경의 상대 휘도 대비로 정한다.

## 공통 테마

기존 화면별 QSS 원본을 보존하고 공통 토큰으로 변환한다. 라이트로 돌아오면 원본 기준으로 다시 계산한다. 직접 그리는 표 · 배지는 `ui_color`를 쓰고 QtCharts 배경 · 축 · 범례도 갱신한다. 판정 · 수치 계산과 회사 AI 대화 내용은 바꾸지 않는다.

Qt 기본 API: [QPalette](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QPalette.html), [시스템 색상 모드](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QStyleHints.html), [QSettings](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QSettings.html).
