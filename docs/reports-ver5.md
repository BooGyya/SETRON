## 화면 구성

| 영역 | 화면 글자 |
| --- | --- |
| 조회 조건 | `기준날짜`(시작 ~ 종료 기간) · `분류`(Memory/Foundry) · `사업장` · `라인` · `설비군`, 조건 초기화 · 검색(돋보기) 아이콘 |
| 보고서 포함 내용 | 오른쪽 위 **[전체 선택]**(모두 체크되면 **[전체 해제]**) |
| 공통 내용 (왼쪽) | 요약 · 적용률 추이 · **히트맵**(사업장 · 분류 · 라인 · 세부라인 · 설비군) · 구성비와 분포 · 위험 판정 근거 · 관측 버전과 원문 근거 |
| 유형별 추가 내용 (오른쪽) | 현황·표준화 · 업그레이드 · Item 배포(아래 `조회할 Item` 드롭다운) · 변경 이력 · AI 분석 |
| 아래 | **[보고서 생성]**, `저장한 보고서` 표(보고서명 · 유형 · 조건 · 생성일시 · 열기) |

각 항목은 **항목명 | 설명**을 한 줄에 둡니다. 항목명은 굵게, 설명은 보조색이며 좁은 화면에서는 설명만 줄바꿈합니다. 별도 도움말 팝업은 없습니다.

## 체크 상태 (정리)

| 시점 | 공통 내용 | 히트맵 보기 | 유형별 추가 내용 |
| --- | --- | --- | --- |
| **처음 열 때** | 모두 체크 | **설비군**만 체크 | **현황·표준화**만 체크 |
| **검색(돋보기)을 누를 때마다** | 모두 체크 | 모두 체크 | 모두 해제 |
| [전체 선택] / [전체 해제] | 모두 체크 / 모두 해제 | 모두 체크 / 모두 해제 | 모두 체크 / 모두 해제 |
| AI 분석 화면에서 "이 종류 · 기간으로" 보고서를 채울 때 | 그대로 | 그대로 | 요청한 유형 하나만 체크 |

- 검색은 날짜 오류 안내가 나와도 먼저 위 기본 선택으로 맞춥니다. 다른 화면의 저장 · 조회가 진행 중이면 체크를 바꾸지 않고 안내만 띄웁니다.
- 검색은 조회 조건만 적용합니다. 보고서를 만들거나 형식 선택 · 미리보기를 열지 않습니다.
- [전체 선택]은 체크 상태만 바꾸며 저장된 자료는 지우지 않습니다. 하나라도 해제하면 다시 [전체 선택]으로 보입니다.
- `조회할 Item`은 Item 배포를 체크했을 때만 켜지고, 해제하면 고른 값을 유지한 채 꺼집니다. 처음 켤 때 Item 목록을 읽습니다.
- 히트맵 보기를 모두 해제하면 히트맵은 출력하지 않습니다(별도 히트맵 체크박스 없음). 세부라인 보기는 세부 구분이 저장된 설비만 보입니다. 조회 조건은 데이터 범위, 히트맵 보기는 같은 데이터를 묶는 방식입니다.

## 생성과 저장

체크한 항목만 미리보기 · Word · PDF · 인쇄에 넣습니다. 공통 내용만, 또는 유형별 내용만 골라도 됩니다.

[보고서 생성]을 누를 때 아래를 검사하고 문제가 있으면 **팝업**으로 알립니다(체크할 때는 안내하지 않습니다).

- 아무 내용도 고르지 않음(`보고서에 포함할 내용을 하나 이상 선택해 주세요.`).
- Item 배포를 골랐는데 Item을 고르지 않음(`조회할 Item을 선택해 주세요.`) · Item 목록을 읽는 중 · 읽기 실패.
- AI 분석을 골랐는데 완료된 AI 답변이 없음(`완료된 AI 답변이 없습니다. …`).
- 시작 날짜가 종료 날짜보다 늦음.
- 생성 결과에서 출력 자료가 없는 공통 내용 · 유형 · 히트맵 보기는 한 팝업에 모아 `선택한 범위에 다음 내용이 없습니다.`로 알리고 형식 선택으로 넘어가지 않습니다. 실제 0%와 미확인 관측값은 자료 없음으로 보지 않습니다.
- 보고서 생성으로 AI를 다시 호출하지 않습니다. 생성 중에는 진행 창에서 취소할 수 있습니다.

출력은 **Word(.docx), PDF(.pdf)** 두 형식입니다. **보고서 생성 → 형식 선택 팝업 → 미리보기** 순서로 진행하며 별도의 ‘생성된 보고서’ 영역은 두지 않습니다. 형식 선택을 취소하면 미리보기나 파일을 만들지 않습니다. 형식을 선택하면 공통 PDF 미리보기가 열리고 인쇄하거나 선택한 형식으로 저장할 수 있습니다. 같은 경로에 같은 파일명이 있으면 확인 후 `(1)`, `(2)` 번호를 이어 붙여 기존 파일을 보존합니다. 저장한 파일 목록은 이 PC의 로컬 설정에 기록합니다.

Word·PDF와 미리보기·인쇄의 모든 페이지에는 오른쪽 하단에 `1`, `2`, `3` 순서의 페이지 번호가 표시됩니다. Word는 자동 PAGE 필드를 사용해 편집 후에도 실제 쪽수로 계산하며, PDF·인쇄는 본문과 분리한 하단 여백에 번호를 표시합니다. AI 분석에서 저장하는 보고서에도 같은 번호 표시를 적용합니다.

## 6차 멘토링 반영 내용

- 적용률 추이를 선택하면 전체 추세와 **설비군별 실제 라인 비교 그래프**를 포함합니다.
- 설비군별 히트맵을 선택하면 **분류 → 사업장 → 설비군 → 원문 라인 → 설비명·색상**을 포함합니다. 첨부된 MM 예시처럼 설비군 머리글 아래 라인 머리글과 색상 셀을 배치합니다. 이후 사용자 요청에 따라 그래프와 히트맵을 포함한 모든 내용은 체크 여부로 결정합니다.
- 그래프와 히트맵은 인쇄용 PNG로 만들어 Word와 PDF에 동일하게 넣습니다. 화면 다크모드와 별개로 흰 종이에 읽히는 색을 사용합니다.
- Memory/Foundry 선택은 집계·그래프·히트맵·위험 목록에 같은 조건으로 적용합니다. 전체를 선택하면 전체 추세 뒤 상세 그림을 분류별로 구분합니다. 분류가 없는 관측은 임의로 분류하지 않습니다.
- P1F/P1D, P4H/P4D, P3-S5 등 명시적 라인명을 줄이거나 새 라인으로 만들지 않습니다. DFB는 C4와 별도로 집계하고 표시합니다.
- 채움색은 기존 버전 판정의 다섯 단계입니다. 위험 후보는 채움색과 독립된 붉은 테두리·문구로 표시하며 위험 목록에 저장된 판정 근거를 함께 표시합니다. 미확인은 안전으로 확정하지 않습니다.
- HPA는 공통 정책대로 목표·위험 분석에서 제외하고, 기준일 현재의 호기·라인·버전을 별도 관측 목록에 보존합니다.
- 사용자용 `SW 계열` 열은 구성비·원문·AI 표에서 제외합니다. 내부 판정의 버전 연결과 목표 N은 유지합니다.

## AI 분석 유형 (11-16 반영)

- 보고서는 AI 분석 화면에서 가장 최근에 완료한 답변을 그대로 씁니다. 질문 · 조회 범위 · 응답 기준일 · 요약 · 원인, 답변의 표(`SW 계열` · `버전 계열` 열 제외), 예측 안내를 넣습니다.
- 답변의 주의 문장은 중복을 지우고 **`AI 주의 사항` 한 항목 안에 `·` 목록**으로 넣습니다. 예전에는 문장마다 제목이 반복됐습니다(11-16 멘토 점검, `ui/report_data.py`).
- 답변 그래프(가로 막대 · 통일 예측 등)는 보고서 메뉴에 넣지 않습니다. AI 분석 화면에서 저장하는 보고서에는 화면 그래프가 캡처되어 들어갑니다([AI 분석](ai-analysis-plan-first.md#그래프와-보고서-1116-멘토-점검)).

## 집계와 페이지 구성

생성할 때 조건·자료·목표 N·판정 규칙을 고정합니다. 데이터 관리에서 수정 후 저장한 내용은 다음 생성에서 다시 읽고, 이미 만든 보고서는 이후 필터 변경이나 DB 수정으로 바뀌지 않습니다. 보고서 경로는 DB에 쓰지 않습니다.

기존 대시보드·Replay·집계 서비스를 재사용합니다. 전체 물리 설비 수와 모델별 버전 판정 건수는 다릅니다. 같은 설비가 여러 설비군의 SW를 쓰면 각 설비군에 표시됩니다. 목표 미지정·미관측·판정 불가는 임의의 0%로 만들지 않습니다. 라인별 관측이 한 장이면 점만 표시하고 날짜 간 값은 보간하지 않습니다.

라인 수는 제한하지 않고 그림 한 장의 범례만 여섯 라인씩 나눕니다. 히트맵은 열당 12행, 그림당 여섯 열을 사용해 긴 라인을 다음 열·그림으로 이어 가며 설비를 생략하지 않습니다. A4에서 그림 너비와 문서 여백을 맞추고 Word 표 머리글은 다음 페이지에도 반복합니다.
