작업 브랜치: `feature/reports-ver5`. 회사 DB·AI의 실데이터 검증은 이 범위에 포함하지 않는다.

요청에 따라 16·56 상단은 데이터 가져오기와 같은 고정 밑줄 탭이다. `뒤로` 버튼은 없으며 `생성 조건으로`와 단계 탭으로 이동한다.
공통 앱 사이드바는 기존 SEMES/SETRON 디자인을 유지한다. 이전 레이아웃의 가짜 사용자·보고서 샘플 행은 만들지 않는다.

후속 사용자 요청에 따라 생성 화면에서는 유형을 다시 선택하지 않고, 첫 화면의 생성 카드에서 선택한 유형명을 글자 길이에 맞는 읽기 전용 배지로 표시한다.
유형 배지는 바깥 테두리와 안쪽 글자를 분리하고 자연 크기로 배치한다. 한글 폭을 수동 고정하지 않아 소수 화면 배율에서도 끝 글자를 자르지 않는다.
생성 조건·출력 설정은 넓은 창에서 8:5 비율과 같은 행의 카드 높이를 유지하되, 전체 높이는 현재 표시 중인 내용에 맞춘다. 비 AI 유형은 포함 항목 바로 아래에 파일명·생성 버튼을 표시하며, AI 유형만 파일명 앞에 AI 전용 입력란을 표시한다. 사용하지 않는 Item·AI 전용 입력란은 공간도 접어 비 AI 유형의 하단 예약 여백을 제거한다.
긴 Item 원문은 선택 모델과 툴팁에 보존하되 카드의 최소 폭을 늘리지 않는다. 좁은 창에서는 카드가 세로로 배치되며 입력란을 숨기거나 자르지 않는다.
첫 화면 오른쪽 위는 `현재 시각`이며 표시 중 자동 갱신한다. DB 기준일·자료 갱신 시각·보고서 생성일이 아니며, 다른 화면으로 이동하면 갱신 타이머를 멈춘다. 보고서의 생성일과 관측 기준일은 각각 기존 값을 유지한다.

## 내용·저장 계약

- 생성 시 조건·목표 N·저장 그룹·관측·판정을 고정한다. 미리보기·파일은 같은 섹션을 사용한다. 이후 조건 초안 변경으로 기존 결과를 다시 계산하지 않는다.
- 기존 집계, Replay 읽기 모델, Item 누적 적용, 업그레이드 우선순위 서비스를 사용한다. DB 쓰기·AI 재호출은 하지 않는다.
- 물리 설비 대수와 설비·계열 건수·분모·판단 불가·SW 미등록·HPA 제외·위험 미확인을 구분한다.
- 선택한 날짜의 관측이 없으면 다른 날짜 자료로 대신하지 않는다. 추이는 실제 관측일만 쓰고 미확인 분모에서 선을 끊는다. 1장 이하는 추이·예측을 만들지 않는다.
- Fab/Line은 명시적 매핑만 사용한다. 관측 원문의 위치가 제공되지 않으면 `원본 위치 미연결`로 표시한다. Item은 전달된 원본 위치를 표시한다.
- 변경 이력은 연속된 실제 관측일의 차이이며 실제 패치 시각이 아니다. 관측 추가·누락도 구별한다.
- AI 해석은 사용자가 명시적으로 불러온 완료 답변만 사용한다. 응답 자체 범위와 보고서 범위는 구분하고 수치 대조 필요를 표시한다. 예제는 회사 AI 결과로 표시하지 않는다.
- Excel에는 수치표를 참조하는 편집 가능한 막대·구성비·꺾은선·트리맵을 넣는다. 트리맵은 기존 chartEx 출력기를 재사용한다. 문자열은 수식이 아닌 원문으로 보존하고 긴 값은 분할 시트로 보존한다.
- Word/PDF에도 같은 조건·수치·주의와 미리보기 그래프를 넣는다. 로컬 임시 파일 완성 후 교체하여 실패 시 기존 파일을 보존한다.
- 저장된 파일 목록은 로컬 설정에 보관하고 기존 AI 보고서 목록도 유지한다. 저장 전 생성 결과는 현재 세션의 최근 2개에서만 다시 열 수 있다. 자료 자체를 설정에 복제하지 않는다.

## 프론트 검증

`tests/test_ui_reports_ver5.py`는 합성 자료로 화면 이동·조건 검증·표시·취소·재시도·불변 결과·최근 목록·3종 파일·Excel 원문 보존을 검증한다.
`tests/test_ui_report_layout.py`는 5개 유형의 배지 폭·긴 Item/AI 질문·넓고 좁은 창에서 카드 영역·비 AI 유형의 파일명 간격·유형 전환 후 버튼 좌표·내용 표시 범위를 검증한다. 현재 시각의 분·날짜 변경과 화면 이동 시 갱신 중지·복귀 시 즉시 갱신도 확인한다.
원본 Excel을 열거나 회사 DB/AI를 호출하지 않는다. 실제 회사 자료의 내용 정확성 검증은 연동 후 별도 수행 대상이다.
