# 보고서

## 생성과 저장

보고서 화면에서 기간·분류(Memory/Foundry)·사업장·라인·설비군과 기존 보고서 유형을 선택한 뒤 조회 또는 보고서 생성을 누릅니다. 선택 도중에는 기존 결과가 바뀌지 않습니다.

유형은 현황·표준화, 업그레이드, Item 배포, 변경 이력, AI 분석을 유지합니다. Item 배포는 해당 Item을 고르고 AI 분석은 완료된 응답을 사용합니다. 보고서 생성으로 AI를 다시 호출하지 않습니다.

유형 버튼 아래의 **보고서 포함 내용** 영역에서 공통 안내는 왼쪽, 유형별 추가 내용은 세로 구분선 오른쪽에 배치합니다. 공통 안내는 고정하고 선택한 유형의 추가 내용만 바꾸며, 중간점 나열 대신 짧은 명사형 문구와 항목별 줄바꿈을 사용합니다. 별도 도움말 팝업은 없습니다.

출력은 **Word(.docx), PDF(.pdf)** 두 형식입니다. 다운로드를 누르면 공통 PDF 미리보기가 열리고 인쇄하거나 선택한 형식으로 저장할 수 있습니다. 같은 경로에 같은 파일명이 있으면 확인 후 `(1)`, `(2)` 번호를 이어 붙여 기존 파일을 보존합니다. 저장한 파일 목록은 이 PC의 로컬 설정에 기록합니다.

Word·PDF와 미리보기·인쇄의 모든 페이지에는 오른쪽 하단에 `1`, `2`, `3` 순서의 페이지 번호가 표시됩니다. Word는 자동 PAGE 필드를 사용해 편집 후에도 실제 쪽수로 계산하며, PDF·인쇄는 본문과 분리한 하단 여백에 번호를 표시합니다. AI 분석에서 저장하는 보고서에도 같은 번호 표시를 적용합니다.

## 6차 멘토링 반영 내용

- 전체 적용률 추이를 유지하고 **설비군별 실제 라인 비교 그래프**를 필수 포함합니다.
- **분류 → 사업장 → 설비군 → 원문 라인 → 설비명·색상**의 히트맵을 필수 포함합니다. 첨부된 MM 예시처럼 설비군 머리글 아래 라인 머리글과 색상 셀을 배치합니다.
- 그래프와 히트맵은 인쇄용 PNG로 만들어 Word와 PDF에 동일하게 넣습니다. 화면 다크모드와 별개로 흰 종이에 읽히는 색을 사용합니다.
- Memory/Foundry 선택은 집계·그래프·히트맵·위험 목록에 같은 조건으로 적용합니다. 전체를 선택하면 전체 추세 뒤 상세 그림을 분류별로 구분합니다. 분류가 없는 관측은 임의로 분류하지 않습니다.
- P1F/P1D, P4H/P4D, P3-S5 등 명시적 라인명을 줄이거나 새 라인으로 만들지 않습니다. DFB는 C4와 별도로 집계하고 표시합니다.
- 채움색은 기존 버전 판정의 다섯 단계입니다. 위험 후보는 채움색과 독립된 붉은 테두리·문구로 표시하며 위험 목록에 저장된 판정 근거를 함께 표시합니다. 미확인은 안전으로 확정하지 않습니다.
- HPA는 공통 정책대로 목표·위험 분석에서 제외하고, 기준일 현재의 호기·라인·버전을 별도 관측 목록에 보존합니다.
- 사용자용 `SW 계열` 열은 구성비·원문·AI 표에서 제외합니다. 내부 판정의 버전 연결과 목표 N은 유지합니다.

## 집계와 페이지 구성

생성할 때 조건·자료·목표 N·판정 규칙을 고정합니다. 데이터 관리에서 수정 후 저장한 내용은 다음 생성에서 다시 읽고, 이미 만든 보고서는 이후 필터 변경이나 DB 수정으로 바뀌지 않습니다. 보고서 경로는 DB에 쓰지 않습니다.

기존 대시보드·Replay·집계 서비스를 재사용합니다. 전체 물리 설비 수와 모델별 버전 판정 건수는 다릅니다. 같은 설비가 여러 설비군의 SW를 쓰면 각 설비군에 표시됩니다. 목표 미지정·미관측·판정 불가는 임의의 0%로 만들지 않습니다. 라인별 관측이 한 장이면 점만 표시하고 날짜 간 값은 보간하지 않습니다.

라인 수는 제한하지 않고 그림 한 장의 범례만 여섯 라인씩 나눕니다. 히트맵은 열당 12행, 그림당 여섯 열을 사용해 긴 라인을 다음 열·그림으로 이어 가며 설비를 생략하지 않습니다. A4에서 그림 너비와 문서 여백을 맞추고 Word 표 머리글은 다음 페이지에도 반복합니다.
