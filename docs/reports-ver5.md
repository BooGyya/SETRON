# 보고서

## 생성과 저장

보고서 화면에서 기간·분류(Memory/Foundry)·사업장·라인·설비군을 정하고 검색(돋보기)을 누르면 조회 조건만 적용합니다. 검색할 때마다 왼쪽 공통 내용과 히트맵 종류는 모두 체크하고 오른쪽 유형별 선택은 모두 해제합니다. 날짜 오류 안내가 나오는 경우에도 같은 기본 선택 상태로 맞춥니다. Item 선택값은 유지하지만 Item 배포가 해제되므로 선택란은 비활성화됩니다. 검색으로 보고서를 생성하거나 형식 선택·미리보기를 열지 않습니다. 체크 항목을 조정한 뒤 별도의 **보고서 생성** 버튼으로 문서를 만듭니다. 선택 도중에는 기존 결과가 바뀌지 않습니다.

**보고서 포함 내용**에서 공통 내용과 유형별 추가 내용을 각각 체크합니다. 공통 내용은 요약, 적용률 추이, 히트맵, 구성비와 분포, 위험 판정 근거, 관측 버전과 원문 근거로 나눕니다. 유형별 추가 내용은 현황·표준화, 업그레이드, Item 배포, 변경 이력, AI 분석을 복수 선택할 수 있습니다. 공통 내용만 선택하거나 유형별 내용만 선택하는 것도 가능합니다.

공통 내용과 유형별 추가 내용은 **항목명 | 설명**을 같은 행에 배치합니다. 체크 항목명은 굵게, 설명은 보조색의 일반 글씨로 구분하며 좁은 화면에서는 설명만 줄바꿈합니다. 체크 항목 바깥에는 테두리를 표시하지 않고 키보드 초점은 글자색으로 구분합니다.

**전체 선택**은 하나의 버튼이며 모든 항목을 체크하면 **전체 해제**로 바뀝니다. 일부라도 해제하면 다시 전체 선택으로 표시합니다. 포함 내용과 히트맵 보기의 체크 상태만 변경하며 저장된 자료는 삭제하지 않습니다. 조회할 Item은 유형별 추가 내용의 Item 배포 바로 아래에 항상 표시하고, Item 배포를 체크한 경우에만 활성화하고 선택을 필수로 검증합니다. 해제하면 기존 선택값을 유지한 채 비활성화합니다.

아무 내용도 선택하지 않았거나 Item 선택이 빠졌거나 완료된 AI 답변이 없으면 **보고서 생성을 눌렀을 때 팝업**으로 안내합니다. 체크박스를 누를 때 자료 없음 문구를 추가하지 않습니다. 선택한 기간·조건에서 출력 자료가 없는 공통 내용/유형/히트맵 보기도 생성 시점에 한 팝업에 모아 안내하고 형식 선택으로 넘어가지 않습니다. 해당 선택이나 조회 조건을 조정해 다시 생성합니다. 실제 0%와 미확인 관측값은 자료 없음으로 처리하지 않습니다. 보고서 생성으로 AI를 다시 호출하지 않습니다.

공통 내용의 적용률 추이 바로 아래에 **히트맵**을 두고, 그 아래에 **사업장, 분류, 라인, 세부라인, 설비군**을 들여쓰기해 하위 항목으로 표시합니다. 좁은 화면에서는 종류들만 들여쓴 영역 안에서 줄바꿈합니다. 별도 히트맵 포함 체크박스 없이 선택한 보기만 보고서에 포함하며 모두 해제하면 히트맵은 출력하지 않습니다. 세부라인 보기는 실제 세부 구분이 저장된 설비만 표시합니다. 상단 조회 필터는 데이터 범위, 히트맵 보기는 같은 데이터를 묶는 방식입니다.

**체크한 항목만** 미리보기·Word·PDF·인쇄에 포함합니다. 처음 열 때는 공통 내용 전체와 현황·표준화, 히트맵 보기는 설비군을 기본 선택합니다. 검색하면 왼쪽 공통 항목과 히트맵 종류가 모두 체크됩니다. 공통 내용과 유형별 내용을 좌우로 구분하고 별도 도움말 팝업은 두지 않습니다.

출력은 **Word(.docx), PDF(.pdf)** 두 형식입니다. **보고서 생성 → 형식 선택 팝업 → 미리보기** 순서로 진행하며 별도의 ‘생성된 보고서’ 영역은 두지 않습니다. 형식 선택을 취소하면 미리보기나 파일을 만들지 않습니다. 형식을 선택하면 공통 PDF 미리보기가 열리고 인쇄하거나 선택한 형식으로 저장할 수 있습니다. 같은 경로에 같은 파일명이 있으면 확인 후 `(1)`, `(2)` 번호를 이어 붙여 기존 파일을 보존합니다. 저장한 파일 목록은 이 PC의 로컬 설정에 기록합니다.

Word·PDF와 미리보기·인쇄의 모든 페이지에는 오른쪽 하단에 `1`, `2`, `3` 순서의 페이지 번호가 표시됩니다. Word는 자동 PAGE 필드를 사용해 편집 후에도 실제 쪽수로 계산하며, PDF·인쇄는 본문과 분리한 하단 여백에 번호를 표시합니다. AI 분석에서 저장하는 보고서에도 같은 번호 표시를 적용합니다.

## 6차 멘토링 반영 내용

- 적용률 추이를 선택하면 전체 추세와 **설비군별 실제 라인 비교 그래프**를 포함합니다.
- 설비군별 히트맵을 선택하면 **분류 → 사업장 → 설비군 → 원문 라인 → 설비명·색상**을 포함합니다. 첨부된 MM 예시처럼 설비군 머리글 아래 라인 머리글과 색상 셀을 배치합니다. 이후 사용자 요청에 따라 그래프와 히트맵을 포함한 모든 내용은 체크 여부로 결정합니다.
- 그래프와 히트맵은 인쇄용 PNG로 만들어 Word와 PDF에 동일하게 넣습니다. 화면 다크모드와 별개로 흰 종이에 읽히는 색을 사용합니다.
- Memory/Foundry 선택은 집계·그래프·히트맵·위험 목록에 같은 조건으로 적용합니다. 전체를 선택하면 전체 추세 뒤 상세 그림을 분류별로 구분합니다. 분류가 없는 관측은 임의로 분류하지 않습니다.
- P1F/P1D, P4H/P4D, P3-S5 등 명시적 라인명을 줄이거나 새 라인으로 만들지 않습니다. DFB는 C4와 별도로 집계하고 표시합니다.
- 채움색은 기존 버전 판정의 다섯 단계입니다. 위험 후보는 채움색과 독립된 붉은 테두리·문구로 표시하며 위험 목록에 저장된 판정 근거를 함께 표시합니다. 미확인은 안전으로 확정하지 않습니다.
- HPA는 공통 정책대로 목표·위험 분석에서 제외하고, 기준일 현재의 호기·라인·버전을 별도 관측 목록에 보존합니다.
- 사용자용 `SW 계열` 열은 구성비·원문·AI 표에서 제외합니다. 내부 판정의 버전 연결과 목표 N은 유지합니다.

## 집계와 페이지 구성

생성할 때 조건·자료·목표 N·판정 규칙을 고정합니다. 데이터 관리에서 수정 후 저장한 내용은 다음 생성에서 다시 읽고, 이미 만든 보고서는 이후 필터 변경이나 DB 수정으로 바뀌지 않습니다. 보고서 경로는 DB에 쓰지 않습니다.

기존 대시보드·Replay·집계 서비스를 재사용합니다. 전체 물리 설비 수와 모델별 버전 판정 건수는 다릅니다. 같은 설비가 여러 설비군의 SW를 쓰면 각 설비군에 표시됩니다. 목표 미지정·미관측·판정 불가는 임의의 0%로 만들지 않습니다. 라인별 관측이 한 장이면 점만 표시하고 날짜 간 값은 보간하지 않습니다.

라인 수는 제한하지 않고 그림 한 장의 범례만 여섯 라인씩 나눕니다. 히트맵은 열당 12행, 그림당 여섯 열을 사용해 긴 라인을 다음 열·그림으로 이어 가며 설비를 생략하지 않습니다. A4에서 그림 너비와 문서 여백을 맞추고 Word 표 머리글은 다음 페이지에도 반복합니다.
