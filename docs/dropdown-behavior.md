# 공통 드롭다운 표시

기준: 2026-11-16, develop f0cfc8d. 코드: `ui/combo_box.py`, `ui/query_filter_popup.py`.

`setron.ui.combo_box.ComboBox`를 앱의 모든 한 줄 선택 필드에서 쓴다. `ui/` 안에서 Qt `QComboBox`를 직접 만드는 곳은 없다. 쓰는 화면: 아이템 매니저(SW 계열 · 적용 Site · 적용 상태), 위험 기준 등록 · 판정 창, 데이터 가져오기(Excel · SQL 탭), 데이터 관리(가져온 엑셀 삭제 포함), 데이터 내보내기(분류), 보고서(조회할 Item), 조회 버전 설정 · 기준 버전 설정 창, 설비 목록, 달력의 연도 · 월 선택 등.

- 선택된 행이 첫 번째 · 중간 · 마지막이어도 목록은 입력칸 아래 4px에서 열린다(`popup_gap = 4`). 현재 행에 맞춰 입력칸 위로 겹치지 않는다.
- 목록 순서와 선택값은 바꾸지 않는다. 긴 목록은 제한된 높이 안에서 스크롤하고 현재 선택 행은 보이게 둔다.
- 화면 끝의 스크롤 가능한 필드는 필요한 공간을 잠시 확보한다. 선택 · 취소 · 바깥 클릭으로 닫히면 여백과 스크롤 위치를 되돌린다.
- 화면 밖으로 가로로 넘치지 않게 팝업 폭 · 위치를 제한한다. 직접 입력 · 키보드 선택 · 비활성 후보 · 선택 신호는 기존 Qt 동작을 쓴다.
- 스크롤바 자체, 우클릭 메뉴, 내보내기 명령 메뉴, 달력의 날짜 표는 바꾸지 않는다.

Qt의 기본 `QComboBox`를 확장하고 `QProxyStyle`로 메뉴형 겹침만 해제한다. 별도 선택 엔진 · 키보드 처리 · 모델 재정렬은 만들지 않는다.
참고: [QComboBox 공식 문서](https://doc.qt.io/qt-6/qcombobox.html), [QProxyStyle 공식 문서](https://doc.qt.io/qt-6/qproxystyle.html).

## 조회 조건 필드는 드롭다운이 아니다

대시보드 · 버전 히트맵 · 버전 리플레이 · 보고서 위쪽의 `분류` · `사업장` · `라인` · `설비군`은 `ComboBox`가 아니라 버튼이다. 누르면 다중 선택 팝업(`ui/query_filter_popup.py`, 제목 `… 선택`)이 열린다. 팝업에는 검색칸(`… 검색`), `N개 선택 중`, [전체 선택]/[전체 해제], [선택 완료]가 있고, 하나도 고르지 않으면 `하나 이상 선택해 주세요`로 막는다. 버튼 글자는 `전체`, 한 개면 그 이름, 여러 개면 `첫 이름 외 N개`다.

## 프론트 검증

`tests/test_ui_combo_box.py`에서 선택 위치별 앵커, 긴 목록, 하단 공간 확보 · 복원, 마우스 · 키보드 선택, 비활성 후보, 직접 입력 취소, 빈 필드를 확인한다. 소스 검사와 앱 전체 위젯 검사로 공통 부품 적용 누락도 막는다. 회사 DB · AI · Excel 연결이 필요 없다.
