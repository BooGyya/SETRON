# 공통 드롭다운 표시

`setron.ui.combo_box.ComboBox`를 모든 앱 선택 필드에서 사용한다. 보고서의 기간·Site·Group·형식뿐 아니라 공통 조회, 설비 목록, Item 매니저, 데이터 가져오기·삭제, Replay, 버전관리·관리 폼, 목표 N·버전 그룹 및 달력의 연도·월 선택에도 적용한다.

- 선택된 행이 첫 번째·중간·마지막이어도 목록은 입력칸 아래 4px에서 열린다. 현재 행에 맞춰 입력칸 위로 겹치지 않는다.
- 목록 순서와 선택값은 바꾸지 않는다. 긴 목록은 제한된 높이 안에서 스크롤하고 현재 선택 행은 보이게 유지한다.
- 화면 끝의 스크롤 가능한 필드는 필요한 공간을 잠시 확보한다. 선택·취소·바깥 클릭으로 닫히면 여백과 스크롤 위치를 복원한다.
- 화면 밖으로 가로로 넘치지 않게 팝업 폭·위치를 제한한다. 날짜 확정·직접 입력·키보드 선택·비활성 후보·선택 신호는 기존 Qt 동작을 사용한다.
- 스크롤바 자체, 우클릭 메뉴, 내보내기 명령 메뉴, 달력의 날짜 표는 변경하지 않는다.

Qt의 기본 `QComboBox`를 확장하고 `QProxyStyle`로 메뉴형 겹침만 해제한다. 별도의 선택 엔진·커스텀 키보드 처리·모델 재정렬은 만들지 않는다.
참고: [QComboBox 공식 문서](https://doc.qt.io/qt-6/qcombobox.html), [QProxyStyle 공식 문서](https://doc.qt.io/qt-6/qproxystyle.html).

## 프론트 검증

`tests/test_ui_combo_box.py`에서 선택 위치별 앵커, 긴 목록, 하단 공간 확보·복원, 마우스·키보드 선택, 비활성 후보, 직접 입력 취소, 빈 필드를 확인한다. 소스 검사와 앱 전체 위젯 검사로 공통 부품 적용 누락도 막는다. 기존 달력·휠 방지 및 각 업무 화면 테스트도 회귀 검증한다. 회사 DB·AI·Excel 연결을 필요로 하지 않는다.
