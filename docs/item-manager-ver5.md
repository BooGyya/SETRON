## 앱에서 확인하는 위치

- 좌측 `아이템 매니저` → 상단 고정 `Item 분석` / `Item 관리` 탭.
- `Item 분석` → 계열 칩 아래 질문 입력·AI 검색 → 원본 표 위 파란 답변 카드. 선택한 Item의 원본 근거 행은 노란색으로 표시한다.
- 원본 표의 문서·시트 선택에서 실제 원본 열을 변경한다. 보관된 원본이 없으면 현재 관리값 표임을 명시한다. JIRA·비고 등의 값을 만들어 넣지 않는다.
- 답변 아래 이동 버튼: AI 분석은 팀원 작업의 대화 화면에 초안만 전달한다. 히트맵/대시보드는 선택 계열·관측일·포함 기준 N을 명시적으로 적용한다. 검색 자체는 전역 조건을 변경하지 않는다.
- `Item 관리` → 상단 5개 필터 / 가운데 등록 기준 카드 / 아래 설비별 PM 상태 표 / 오른쪽 `+ 위험 아이템 추가`.
- 추가 창은 이름·구분·원본 Item·판정 방식·복수 설비군·Site/Line·메모를 받는다. `영향 미리보기`와 원본 확인 체크 후에만 `추가`할 수 있다. 취소·입력 변경·중복 클릭은 저장하지 않는다.

## 저장 호환성과 예외

- SQL 스키마 변경 없이 기존 `risk_rule.target_reference.item_manager` JSON에 표시 정보와 검증된 범위를 보관한다. 기존 재연결 근거는 유지한다. 공통 위험 판정기에도 모델·위치 범위를 적용하므로 관리 화면에만 존재하는 장식용 필터가 아니다.
- 공정 위험/기타는 분류명이다. 사용자가 기존 필수 Item/위험 버전/결함 범위 중 판정 방식을 명시적으로 선택한다. 새 제조 정책을 임의로 추가하지 않는다.
- 저장된 N 그룹이 해당 모델·계열에 우선 적용 중이면 자동 이동으로 이를 덮어쓰지 않고 기준 확인을 안내한다. 적용 근거·버전 순서 미확인도 같은 방식으로 차단한다.
- 미연결·빈 자료·AI 실패·검증 실패는 0대/안전 확정으로 표시하지 않는다. AI 미연결 시 키워드 조회임을 구분한다. AI 후보는 한 계열 500개까지 검증하며 초과 시 원문 키워드 조회를 안내한다.
