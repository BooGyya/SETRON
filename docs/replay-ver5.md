### 조회

- 처음 들어오면 저장된 분석 기준일의 첫날 ~ 마지막 날로 기간을 채우고 바로 조회한다.
- 조건을 바꾼 뒤 조회(돋보기)를 눌러야 반영된다. 바꾸고 누르지 않았으면 `조회 조건이 변경되었습니다. 데이터 조회를 눌러 적용해 주세요.`를 보이고 재생을 막는다.
- 시작이 종료보다 늦으면 `시작 날짜는 종료 날짜와 같거나 앞서야 합니다.`
- 기간 안에 저장일이 없으면 `기간 안에 저장된 관측일이 없습니다.`, 시점이 2개 미만이면 `재생하려면 조건에 맞는 실제 관측일이 두 개 이상 필요합니다.`
- 목표 N은 대시보드에 적용된 목표를 쓴다. [기준 버전 설정]에서 저장한 뒤 다시 조회하면 반영된다.

### 조회 버전 설정 팝업

창 제목 `SETRON · 조회 버전 설정`. `설비군` 드롭다운(`전체 설비군` + 설비군), **[전체 선택]**(모두 고르면 **[전체 해제]**), `N개 선택 중`, 버전 체크 목록(`버전 미등록 포함` 포함), **[취소]** / **[확인]**.

- 버전을 하나도 고르지 않으면 `조회할 버전을 하나 이상 선택해 주세요.`로 막는다.
- 설비군을 바꿔도 다른 설비군에서 고른 버전은 유지한다.
- [확인] 뒤 버튼 글자가 `조회 버전 설정 · N개 선택`으로 바뀐다. 조회를 눌러야 결과가 바뀐다.
- 버전 다중 선택은 **조회 범위(OR)**이며 목표 N을 정하는 기능이 아니다.

### 재생 간격

- **지정 일수**: 처음에는 실제 저장일마다 시점을 만든다. 다시 누르면 `일수 간격 입력` 창(취소 / 적용)에서 일 수를 정하고, 시작 날짜부터 그 간격으로 시점을 만든다.
- **1주 · 1개월 · 3개월**: 시작 ~ 종료를 간격으로 끊은 날짜마다 시점을 만든다. 저장되지 않은 날짜는 그 전 마지막 저장일 자료로 계산한다(달성률 툴팁에 `마지막 저장일 … 기준`).
- 간격을 바꿔도 다시 조회하지 않는다. 시점이 2개 미만이 되는 간격은 고를 수 없다. 재생 중에 바꾸면 보던 날짜부터 이어서 재생한다.

### 재생

- 1× 기준 1초마다 다음 시점으로 간다. 배속에 맞춰 간격이 줄거나 는다. 마지막 시점에서 멈춘다. 마지막에서 ▶를 누르면 처음부터 재생한다.
- 재생 위치 막대(11-13 요청): 시점이 2개 이상일 때만 쓸 수 있다. 끄는 동안에는 툴팁만 바뀌고, 손잡이를 놓으면 그 시점을 보인다. 재생 중이었으면 이어서 재생한다. 재생 중에는 막대가 현재 시점을 따라간다.
- 추이 그래프의 점을 누르면 그 시점으로 이동한다(재생은 멈춤).
- 화면을 떠나면 재생을 멈추고, 열린 팝업 · 설비 상세를 닫는다.

### 달성률 추이 · 히트맵

- 추이: 분류별 꺾은선, 세로축 `목표 N 이상 적용률 (%)`. 판정 불가 날짜는 선을 끊는다.
- 설비군 분류에서 칩을 끄면 그래프 선 · 전체 적용률 · 히트맵이 고른 설비군으로 함께 바뀐다(요청 2-2, `선택 설비군` 표시). 다른 분류의 범례는 추이 선 표시만 바꾼다.
- 히트맵: 버전 히트맵과 같은 타일 · 목록 · 검색 · 필터 도구를 고정된 시점 자료에 쓴다. 타일을 누르면 읽기 전용 설비 상세 패널([히트맵 설비 상세](heatmap-detail-sidebar.md))이 열린다.
- 전체 적용률 툴팁: `등록 SW 목표 달성 a / b건 · %`, 분석 대수(이날 저장 n대 · 이전 관측 이어받음 m대), HPA 제외 대수, 판단 불가 건수(분모 제외), 정보 부족 사유.

## 표시와 데이터 원칙

- 조회할 때 관측 자료 · 목표 N · 위험 판정을 고정한다. 재생 · 시점 이동 · 분류 · 간격 변경은 고정된 자료만 쓴다. 다른 메뉴의 조회 조건은 바꾸지 않는다.
- 각 시점은 대시보드처럼 **그 날짜까지 설비별 최신 관측**으로 계산한다(QA R-01). 그날 저장되지 않은 설비는 이전 마지막 관측을 이어받으며, 툴팁에 이어받은 대수를 따로 적는다.
- 목표 N 미지정은 조회 실패가 아니라 판정 불가로 표시한다. 판정 불가를 0%로 그리지 않는다.
- HPA는 목표 분석 · 재생 타일에서 빼고 제외 대수로만 보인다. 과거 시점에 최신 HPA를 끼워 넣지 않는다.
- 목표 달성 분모는 `달성 + 미달`인 **설비 · SW 계열 건수**다. 물리 대수와 구분한다.
- 저장 자료가 바뀌면(관리 저장 · 가져오기) 재생을 멈추고 `저장 자료가 변경되었습니다. 조회 조건을 다시 선택해 주세요.`를 보인다. 늦게 온 조회 응답은 버린다.

## 프론트 확인 순서

1. 버전 리플레이 진입 → 기간 · 조건 · [조회 버전 설정] 후 조회.
2. [달성률 추이] / [히트맵] 전환, 분류 탭 전환 시 같은 시점이 유지되는지 확인.
3. ▶ → ‖ → ↺, 배속 변경, 재생 위치 막대 끌기 · 놓기, 마지막 시점 정지 확인. 화면 이탈 시 정지 확인.
4. 재생 간격(지정 일수 · 1주 · 1개월 · 3개월) 전환과 비활성 조건 확인.
5. 설비군 칩 끄기 → 선 · 적용률 · 히트맵이 함께 바뀌는지 확인.
6. 히트맵 타일 클릭 → 상세 패널 열기 · 닫기 확인.
7. 버전 팝업의 전체 선택/해제 · 취소 · 확인 · 0개 차단 확인.
