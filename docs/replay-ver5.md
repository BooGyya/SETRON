## 표시와 데이터 원칙

- 조회 적용 시 관측 자료·N·위험 판정 결과를 고정한다. 타이머와 타일 클릭은 고정된 메모리 자료만 사용한다. 다른 메뉴의 조회 초안·목표 N은 바꾸지 않는다.
- 목표 N 미지정은 조회 실패가 아니라 판정 불가로 표시한다. 읽기 공급자의 모델 적용 근거가 무효인 N도 임의로 유효한 N으로 바꾸지 않고 판정에서 제외한다.
- 팝업은 사용자 확인에 따라 **버전 다중 선택 조회(OR)**다. 버튼은 현재 Figma 문구를 유지하지만 N을 지정하거나 여러 N을 만드는 기능이 아니다. 선택 완료 후 조회 적용해야 결과가 바뀐다. 0개 선택은 차단한다.
- 날짜 범위 안의 실제 관측만 사용한다. 누락 설비를 직전 날짜에서 복사하거나 관측 없는 날짜를 생성하지 않는다. 판정 불가 날짜에서는 차트 선을 끊는다.
- 재생 가능 조건은 선택 범위의 정상 설비가 관측된 날짜 2개 이상이다. 한 날짜는 조회할 수 있으나 재생은 비활성화한다. 빈 결과·실패·잘못된 날짜는 이전 결과와 섞지 않는다.
- HPA는 목표 분석·재생 타일에서 제외하고 집계의 제외 대수로 보존한다. 과거 시점에 별도의 최신 HPA를 끼워 넣지 않는다.
- 목표 달성 분모는 기존 계약대로 `달성 + 미달`인 **설비·SW 계열 건수**다. 복수 SW가 있으므로 디자인 예시의 `48 / 80대`를 고정하지 않고 `건`으로 정확히 표시한다. 물리 대수·판정 불가·HPA 제외는 도구 설명으로 구분한다.
- Site/Fab/Line은 공급자가 전달한 명시적 매핑만 사용한다. 원본 구역으로 Fab/Line을 추정하지 않는다. 현재 읽기 공급자의 위치 매핑 계약은 변경하지 않는다.
- 화면 이탈·조건 변경·저장 자료 변경 시 재생을 정지한다. 조회 워커의 늦은 응답은 무시한다. 관리 저장 중에는 Replay도 잠그며 완료 후 다시 조회해야 한다.

## 프론트 확인 순서

1. Version Replay 진입 → 날짜·범위·버전 선택 후 조회 적용.
2. 날짜 칩을 선택해 제목·강조색·달성률·히트맵이 같은 관측일로 바뀌는지 확인.
3. 재생 → 일시정지 → 처음부터 → 마지막 시점 정지 확인. 페이지 이탈 시 정지 확인.
4. 범례를 껐다 켜서 차트만 바뀌고 대수·타일은 그대로인지 확인.
5. 타일을 클릭해 해당 날짜의 상세 패널과 펼침/접기·닫기 확인.
6. 버전 팝업의 전체/해제/취소/완료·0개 선택 차단 확인. 빈 기간·잘못된 날짜·단일 관측일 상태 확인.

자동 검증은 `tests/test_replay_data_ui.py`, `tests/test_ui_replay_ver5.py`에 있다. 합성 자료로 프론트 동작을 확인하며 실제 회사 AI/DB/Excel을 호출하거나 저장 자료를 변경하지 않는다.
